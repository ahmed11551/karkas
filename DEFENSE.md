# Каркасник — 5 слайдов для защиты

## 1. Проблема
Сложно быстро понять цену дачного каркасного дома и оставить заявку без звонка менеджеру: разрозненные каталоги, «узнайте у менеджера», нет единого следа заявки.

## 2. Решение
Не просто лендинг, а интерактивный сервис продажи: клиент сам выбирает проект, считает смету, проходит квиз и оставляет лид — менеджер сразу видит его в CRM.

## 3. Архитектура
React 19 + Vite · Express (`server.ts`) · JSON CRM (`data/leads.json`) · SSE realtime · HttpOnly-сессия админа · RU/EN, light/dark, PWA-ready.

## 4. Фичи
- Каталог 15 проектов с визуализациями и планами  
- Живой калькулятор + фиксация цены  
- Квиз с заявкой  
- Смета (печать / PDF / ссылка)  
- CRM: статусы, заметки, фильтры, CSV, SSE, источник и UTM заявки  
- i18n, темы, валидация телефона и согласия (152-ФЗ)

## 5. Демо
- Локально: `http://localhost:3000` (`npm run dev`)  
- Временный публичный URL: `npx localtunnel --port 3000` (сервер должен слушать `HOST=0.0.0.0`)  
- CRM: `/login` · локальный `.env`: `admin` / `KarkasnikDemo2026`  
- Сквозной путь: калькулятор → заявка · квиз → заявка · обе видны в CRM

**Скриншоты на защиту:** Hero · Calculator · CRM со свежими лидами.
